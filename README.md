# Siddhiksha Global Technologies Pvt Ltd - Static Website

Modern, responsive enterprise website for **Siddhiksha Global Technologies Pvt Ltd**.

## 🚀 100% Static Web Hosting Compatible
This website is completely self-contained HTML5, CSS3, and JavaScript with **zero PHP backend dependencies**. It can be deployed immediately on any static web hosting platform:

- **Netlify** (drag-and-drop or Git)
- **Vercel**
- **GitHub Pages**
- **Cloudflare Pages**
- **AWS S3 / CloudFront**
- **Firebase Hosting**
- **cPanel / Apache / Nginx** (upload to `public_html`)

## 📁 Project Structure
- `index.html` - Main landing page (Enterprise IT, Digital Commerce, Services, FAQ, Contact)
- `css/` - Custom responsive stylesheets (Brand colors: Navy Blue `#1B2A4A`, Gold `#C5A55A`)
- `images/` - High-resolution assets, icons, and official SGV logo
- `js/` - Interactive functionality, smooth scrolling, counters, and static form handler
- `lib/` - Vendor libraries (Bootstrap, OwlCarousel, Lightbox, Waypoints)
